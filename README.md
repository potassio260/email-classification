# University Email Sorter

> An automated email classifier built to filter out university spam, organize class updates, and declutter your student inbox.

## The Problem
If you are a university student, you know the struggle: your inbox is a chaotic mess. Universities often spam everything they can with no clear order or meaning, leaving you to sift through announcements for classes you aren't taking and events you aren't interested in.

I got tired of the clutter, so I decided to build a solution. **University Email Sorter** is a machine learning tool designed to automatically categorize and filter out academic spam so you can focus on what actually matters.

## Help Wanted: Dataset Needed
Currently I use my own emails for model training, but obviosly that doesnt really follow the format for a good traing data set.
The foundation of this project is built, but an AI is only as good as its training data. I am currently looking for a comprehensive dataset of student emails to properly train and fine-tune the classification model. 

If you know of any open-source datasets or want to contribute your anonymized inbox data, please feel free to open an issue or reach out!
